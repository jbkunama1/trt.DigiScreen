📦 Setup

📦 Setup

Projektordner anlegen

Create project folder

mkdir -p /opt/digiscreen/{html,assets}
cd /opt/digiscreen

Digiscreen-Vollpaket entpacken

Extract Digiscreen package

ZIP von gitlab.eldshort.de laden:

Download ZIP from gitlab.eldshort.de:

unzip ~/Downloads/digiscreen-*.zip -d /opt/digiscreen/html

Eigenes Hintergrundbild

Custom background image

cp /pfad/zu/background.jpg /opt/digiscreen/html/assets/background.jpg

Repo klonen & Image bauen

Clone repo & build image

git clone https://github.com/jbkunama1/trt.DigiScreen.git /opt/digiscreen
cd /opt/digiscreen
docker compose build --no-cache

Container starten

Start container

docker compose up -d
# http://SERVER_IP:8080

🔄 Wöchentliches Update (Cron)

🔄 Weekly Update (Cron)

chmod +x /opt/digiscreen/update_digiscreen.sh
sudo crontab -e

⏰ Jeden Sonntag 03:00 Uhr:

⏰ Every Sunday at 03:00 AM:

0 3 * * 0 /opt/digiscreen/update_digiscreen.sh >> /var/log/digiscreen-update.log 2>&1

🦊 GitLab Mirror

Bei jedem Push auf main wird automatisch ein Mirror auf GitLab Branch github-mirror gepusht. Dein originaler GitLab-main bleibt unberührt.

On every push to main, a mirror is automatically pushed to GitLab branch github-mirror. Your original GitLab main is never touched.
