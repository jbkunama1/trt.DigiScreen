📦 Setup

📦 Setup

Repo klonen

Clone repo

git clone https://github.com/jbkunama1/trt.DigiScreen.git /opt/digiscreen
cd /opt/digiscreen

Vollpaket herunterladen & entpacken

Download & extract full package

wget "https://gitlab.eldshort.de/uivens/digiscreen/-/raw/main/releases/1.0.8/digiscreen_compiled_1.0.8.zip" \
     -O digiscreen.zip
unzip digiscreen.zip -d /opt/digiscreen/html

Container starten

Start container

docker compose up -d --build
# http://SERVER_IP:8080

Eigenes Hintergrundbild (optional)

Custom background (optional)

cp mein-bild.jpg /opt/digiscreen/html/assets/custom/bg_mein_bild.jpg
docker compose restart

🔄 Auto-Update (Cron)

🔄 Auto-Update (Cron)

chmod +x /opt/digiscreen/update_digiscreen.sh
sudo crontab -e
# 0 3 * * 0 /opt/digiscreen/update_digiscreen.sh >> /var/log/digiscreen-update.log 2>&1

🦊 GitLab Mirror

Bei jedem Push auf main wird automatisch auf GitLab Branch github-mirror gespiegelt.

On every push to main, an automatic mirror is pushed to GitLab branch github-mirror.
