📦 Setup

Projektordner anlegen

mkdir -p /opt/digiscreen/{html,assets}
cd /opt/digiscreen

Digiscreen-Vollpaket entpacken

ZIP von gitlab.eldshort.de herunterladen, dann:

unzip ~/Downloads/digiscreen-*.zip -d /opt/digiscreen/html

Eigenes Hintergrundbild einsetzen

cp /pfad/zu/background.jpg /opt/digiscreen/html/assets/background.jpg

Repo klonen & Image bauen

git clone https://github.com/jbkunama1/trt.DigiScreen.git /opt/digiscreen
cd /opt/digiscreen
docker compose build --no-cache

Container starten

docker compose up -d
# http://SERVER_IP:8080

🔄 Wöchentliches Update (Cron)

chmod +x /opt/digiscreen/update_digiscreen.sh
sudo crontab -e

⏰ Cron-Eintrag (jeden Sonntag 03:00 Uhr):

0 3 * * 0 /opt/digiscreen/update_digiscreen.sh >> /var/log/digiscreen-update.log 2>&1

⚙️ Portainer Stack

Portainer → Stacks → Add stack → docker-compose.yml hochladen → Deploy the stack.
